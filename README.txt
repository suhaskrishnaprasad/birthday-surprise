BIRTHDAY SECRET WEBSITE — STARTER

1. Open index.html in a browser to preview the first two screens.
2. Open index.html in a text editor (Notepad or VS Code).
3. Near the bottom, find:
     const SECRET_PASSWORD = "oursecret";
     const PASSWORD_HINT = "Something only the two of us would know...";
   Change these to your own password and hint.
4. The two photo placeholders can later be replaced with your actual couple photos.
5. When the design is ready, publish the folder using a free static host such as GitHub Pages or Netlify.
   Then generate a QR code pointing to the published website URL.

Note: This starter password is a front-end surprise gate, not strong security. Do not use a real or sensitive password.
